#MESSAGES (STATE)
1. state is created with messages variable. this holds al the ai messages and user messages
2. this state is passed in the laggraph node (chatbot node) so that the node can access it anytime for context

class ChatState(TypedDict):
    messages: Annotated[list[BaseMessage], add_messages]

here, add_messages is reducer (reducer is used to append the convo history to the messages variable). another function is when it sees a message with an ID which is already there in the history, it just replaces the old text. annotated also helps achieving the same "append" logic

3. at the end of the node, we update the global state with the response of the AI
